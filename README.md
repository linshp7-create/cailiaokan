# 材料刊

材料化学阅读器。在手机上像刷小红书一样读 **JACS / Angew / ACS Nano**。与金融顶刊阅读器「五大刊」是两条产品线，互不影响。

当前第一版只收这三本。Nature Chemistry、Advanced Materials、Nature / Science 材料精选等以后再加。

安装包发布后见 [Releases](https://github.com/linshp7-create/cailiaokan/releases)。打开应用会从本仓库拉取最新目录；有新安装包时应用内提示更新。

## 读什么

| 卡片缩写 | 全称 |
| --- | --- |
| **JACS** | Journal of the American Chemical Society |
| **Angew** | Angewandte Chemie International Edition |
| **ACS Nano** | ACS Nano |

目录覆盖 2026 年已出各期，以及 ASAP / Early View。正式出刊后，早报里的文章会归到对应那一期。

数据文件：[data/journal-data.json](data/journal-data.json)（目录就绪后提交）。工作日早上核对出版社源；有新文或新一期就写入。打开 App 即可拉到，不必重装。

## 交付标准（与五大刊相同）

1. 手机上读刊，不在对话里排队出卡片。
2. 一屏很多张，双列瀑布流。不是一页一张。
3. 两层阅读：卡片只负责扫，点进去看摘要、对话、笔记。
4. 中英分开：英文标题用文字印在图上（不生成图片）；下面只出中文译名，有翻译才显示。
5. 刊名用英文缩写。
6. 已读要记；随机流里已读降权，但不隐藏。
7. 收藏、想法、浏览记录、API 密钥、对话、译文只留在手机。
8. 目录和安装包分开更新：新文只改 JSON；改界面才发新 APK。

## 四个栏

**期刊** 杂志封面 → 选 2026 某一期 → 期内双列卡片。

**早报** 还没进正式刊的 ASAP / Early View。

**随机** 双列推荐流。未读优先，已读少出；三刊交错。

**我的** 收藏、笔记、已读、浏览记录，以及本机翻译 / 对话接口。

## 翻译和问答（可选）

在「我的」填写自己的 OpenAI 兼容接口。密钥只存在手机，不进本仓库、不进 APK。不填也能读刊、收藏、做笔记。

## 隐私

本仓库公开的是期刊公开目录（标题、作者、摘要、DOI、链接）。密钥和阅读记录不上传。

论文版权归各期刊与出版社。本项目只做个人阅读入口，不提供全文 PDF。
